Cette application permet de gérer des salles (ajout, modification, suppression, recherche).
- Python
- MySQL
- CustomTkinter
- models : contient la classe Salle
- Data : accès à la base de données (DAO)
- services : logique métier
- views : interface graphique
- main.py : point de démarrage
- Ajouter une salle
- Modifier une salle
- Supprimer une salle
- Rechercher une salle
- Afficher la liste des salles
Nom : db_salles
Table : salle(code, description, categorie, capacite)
